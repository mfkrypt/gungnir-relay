# Hosts whose sourcemaps are public-by-design — tracked in state but never alerted.
#
# A .map on cdn.jsdelivr.net/unpkg/cdnjs is not a leak: every npm package ships
# one and the CDN serves it to the world. Alerting on those buries the signal
# that actually matters — *your* code leaking source. Suffix-matched, so an
# entry of example.com also covers cdn.example.com.
#
# Deliberately NOT listed here: site-builder CDNs that host the target's OWN
# build (cdn.prod.website-files.com for Webflow, *.cloudfront.net asset roots).
# Those are the target's code and a .map there IS a finding.
